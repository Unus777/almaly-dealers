# Дилерский портал «Алмалы-Керамик»

Отдельный проект: каталог для оптовых покупателей и бланк заказа.
Витрина с QR-кодами (`almaly-tiles`) не затрагивается — каталог читается из её `data.json`,
поэтому фото и остатки везде одни и те же.

## Страницы

- `docs/index.html` — каталог: поиск, фильтры по формату и покрытию, остатки складов
- `docs/tile.html?a=АРТИКУЛ` — модель: фото, характеристики, выбор количества упаковок и склада
- `docs/order.html` — бланк заказа: заказчик, доставка, оплата, позиции; печать/PDF,
  отправка в WhatsApp, почтой или копированием текста
- `docs/manager.html` — журнал заявок для продавцов: заявка открывается по ссылке из письма
  или WhatsApp, принимается в журнал, ведутся статусы, выгрузка в CSV

## Настройка

Все контакты — в `docs/config.js`: телефон, почта, номер WhatsApp менеджера.
Их надо заменить на рабочие: они попадают в бланк и в кнопки отправки.

## Что стоит добавить позже

Общий список заявок для всех менеджеров (сейчас журнал живёт в браузере того, кто открыл ссылку).
Делается приёмом заявок в Google-таблицу через Apps Script — примерно 15 минут работы.
