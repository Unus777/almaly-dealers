# Дилерский портал «Алмалы-Керамик»

Каталог для оптовых покупателей, оформление заявки и панель продавца.
Витрина с QR-кодами (`almaly-tiles`) не затрагивается — каталог читается из её `data.json`,
поэтому фото, новинки и остатки везде одни и те же.

## Страницы

- `docs/index.html` — каталог: поиск, фильтры, остатки складов, бейджи новинок
- `docs/tile.html?a=АРТИКУЛ` — модель: галерея, характеристики, **ввод в м²** с пересчётом
  в целые упаковки, вес и склад отгрузки
- `docs/order.html` — оформление: позиции, данные заказчика, доставка и оплата,
  отправка заявки, упаковочный лист с номером заявки (печать/PDF)
- `docs/admin.html` — панель продавца: заявки, статусы, контакты дилера в один клик,
  печать листа, выгрузка CSV

## Приём заявок

Серверная часть — Google Apps Script, разворачивается за 5 минут: см. `apps-script/README.md`.
После развёртывания адрес веб-приложения вписывается в `docs/config.js` → `ORDERS_API`.
Пока он пустой, заявка уходит менеджеру в WhatsApp, а упаковочный лист сохраняется в PDF.

## Настройка

`docs/config.js` — телефон, почта и WhatsApp менеджера (сейчас заглушки), адрес приёма заявок.
