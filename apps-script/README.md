# Приём заявок: настройка за 5 минут

Заявки дилеров складываются в вашу Google-таблицу, панель продавца читает их оттуда.
Ничего оплачивать и настраивать на сервере не нужно.

1. Создайте новую Google-таблицу (или откройте рабочую) → меню **Расширения → Apps Script**.
2. Удалите содержимое файла `Код.gs` и вставьте туда весь текст из `Code.gs` этой папки.
3. В начале файла задайте:
   - `ADMIN_CODE` — должен совпадать с паролем продавца из `docs/config.js` (сейчас `admin`);
   - `NOTIFY_EMAIL` — почта для уведомлений о новых заявках (можно оставить пустой).
4. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - «Запуск от имени» — **от моего имени**;
   - «У кого есть доступ» — **у всех**.
   Нажмите «Развернуть», подтвердите доступ к таблице и почте.
5. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`
   и вставьте его в `docs/config.js` в строку `const ORDERS_API = '…';`

После публикации сайта заявки начнут приходить в лист «Заявки» и в панель продавца
(`admin.html`, вход по коду из шага 3).

## Уведомления о новых заявках

В `Code.gs` заполните нужное — заявка сразу после записи в таблицу уходит по этим каналам:

- `NOTIFY_EMAIL` — почта, куда придёт письмо со всей заявкой.
- `TELEGRAM_TOKEN` и `TELEGRAM_CHAT` — уведомление в Telegram (приходит за секунды, звук на телефоне).

Как получить Telegram:

1. В Telegram напишите **@BotFather** → `/newbot`, придумайте имя. Он вернёт токен вида
   `123456789:AA...` — это `TELEGRAM_TOKEN`.
2. Напишите своему боту любое сообщение (или добавьте его в группу менеджеров и напишите там).
3. Откройте в браузере `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите
   `"chat":{"id":...}` — это число (у группы оно с минусом) впишите в `TELEGRAM_CHAT`.
4. В редакторе Apps Script выберите функцию `testNotify` и нажмите «Выполнить» — должно прийти
   тестовое сообщение. Первый запуск попросит разрешения на отправку почты и обращение к сети.
5. **Развернуть → Управление развёртываниями** → карандаш → «Версия» — **Новая версия** → «Развернуть».

Пока панель продавца открыта, она и сама предупреждает о новых заявках: звуковой сигнал
и системное уведомление (включается в меню «Ещё → Включить уведомления о заявках»).

## Обновление кода

Если вы уже разворачивали приложение, а `Code.gs` в репозитории обновился (например, появилось
действие `track` — статусы заявок для дилера в разделе «Мои заявки»), нужно перезалить код:

1. **Расширения → Apps Script**, замените содержимое `Код.gs` новым текстом из `Code.gs`.
2. **Развернуть → Управление развёртываниями** → карандаш у текущего развёртывания →
   «Версия» — **Новая версия** → «Развернуть».
   Так адрес `ORDERS_API` остаётся прежним и менять `docs/config.js` не нужно.

До обновления сайт работает как раньше: в «Моих заявках» вместо статуса будет
«статус уточняется у менеджера».

Пока `ORDERS_API` пустой, сайт работает без сервера: заявка уходит менеджеру в WhatsApp,
а упаковочный лист сохраняется в PDF.
