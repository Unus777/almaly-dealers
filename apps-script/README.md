# Приём заявок: настройка за 5 минут

Заявки дилеров складываются в вашу Google-таблицу, панель продавца читает их оттуда.
Ничего оплачивать и настраивать на сервере не нужно.

1. Создайте новую Google-таблицу (или откройте рабочую) → меню **Расширения → Apps Script**.
2. Удалите содержимое файла `Код.gs` и вставьте туда весь текст из `Code.gs` этой папки.
3. В начале файла задайте:
   - `ADMIN_CODE` — должен совпадать с паролем продавца из `docs/config.js` (сейчас `admin`);
   - `NOTIFY_EMAIL` — почта для уведомлений о новых заявках (можно оставить пустой).
4. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - «Запуск от имени» — **от моего имени**;
   - «У кого есть доступ» — **у всех**.
   Нажмите «Развернуть», подтвердите доступ к таблице и почте.
5. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`
   и вставьте его в `docs/config.js` в строку `const ORDERS_API = '…';`

После публикации сайта заявки начнут приходить в лист «Заявки» и в панель продавца
(`admin.html`, вход по коду из шага 3).

Пока `ORDERS_API` пустой, сайт работает без сервера: заявка уходит менеджеру в WhatsApp,
а упаковочный лист сохраняется в PDF.
